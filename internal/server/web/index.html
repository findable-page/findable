Free & Open-Source API & MCP Tools

Integrate seoscore directly into your CI pipelines, terminal workflows, or AI coding agents.

1. cURL / REST API Endpoint

curl -s -X POST https://seoscore-api.nadimtuhin.workers.dev/api/scan \ -H "Content-Type: application/json" \ -d '{"url":"https://example.com"}'

2. Go CLI (Single Zero-Dependency Binary)

go install github.com/nadimtuhin/seoscore-cli/cmd/seoscore@latest seoscore-cli https://example.com

3. Model Context Protocol (MCP) in Claude / Cursor / Hermes

Add to your claude_desktop_config.json or Cursor MCP settings:

{ "mcpServers": { "seoscore": { "command": "seoscore-cli", "args": ["-mcp"] } } }

4. NPX Node MCP Runner

npx -y seoscore-mcp
