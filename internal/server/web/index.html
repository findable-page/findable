              What is findable?

              findable is a free scanner that scores one web page on traditional SEO, answer engine optimization (AEO) and generative engine optimization (GEO). It runs 70+ page checks, gives you one overall score from 0 to 100, and ranks the fixes by how many points each one recovers.

              SEO
              Search engine optimization. Make the page easy for a search crawler to fetch, read and rank.
              AEO
              Answer engine optimization. Shape the page so an answer box or chat tool can lift a short, correct answer.
              GEO
              Generative engine optimization. Give an AI model facts, authorship and sources it can cite with confidence.

              How is SEO different from AEO and GEO?

              SEO gets your page found and ranked by a crawler. AEO gets a short passage of it chosen as the answer. GEO gets your facts and your name cited inside a generated reply. SEO comes first, because a page that cannot be fetched or read cannot be answered from or cited.

              How do I check my site in three steps?

              1. Paste a page URL into the scan box at the top of this page.
              2. Watch the agent work through the fetch, SEO, AEO and GEO checks.
              3. Do the top three fixes, then scan again to see your score move.

              How do I run findable from a terminal, an AI agent or an API?

              Command line

              go install github.com/nadimtuhin/findable/cmd/findable@latest
findable https://example.com

              MCP server for AI agents

              npx findable-mcp

              REST API

              curl -s -X POST https://findable.page/api/scan \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'

              How is the score calculated?

              The overall score blends three family scores: SEO counts for half, AEO and GEO for a quarter each. Every failing check is worth its family weight divided by that family's check count. That is why the top fixes you see are ranked by recoverable points.

              Frequently asked questions

              Is findable free?

              Yes. It costs $0, needs no signup and the code is MIT licensed on GitHub.

              Does findable ask ChatGPT, Perplexity, Claude or Google AI about my page?

              No. It checks the signals on your page that answer engines can use, such as structured data, direct answers, clear authorship and sources. It does not query any AI product.

              Can it scan more than one page?

              Yes. Crawl Site mode (beta) scans your start page plus internal links, up to 20 pages. The CLI can go further, for example findable -crawl -limit 100 to scan 100 pages.

              How do I use it in CI?

              Run the CLI with -format sarif to upload results to GitHub code scanning. The findable GitHub Action can also fail a build when the score drops below a number you choose.

              What are the site checks?

              With the site option, findable also fetches robots.txt and llms.txt. It reports whether GPTBot, ClaudeBot, PerplexityBot and Google-Extended are blocked. These are shown apart from the score.

              What limits does a scan have?

              A scan reads up to 5MB of a page and gives up after 10s. It fetches public hosts on ports 80 and 443 only.

              How do I contact the author?

              Open an issue on GitHub with a bug, a question or a check you want added. The source is at github.com/nadimtuhin/findable.
